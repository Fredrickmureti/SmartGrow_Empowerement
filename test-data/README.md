# ERP Test Data

This folder contains comprehensive sample data for testing all modules of the ERP system. Copy and paste this data when manually testing features.

## Structure

| File | Module | Description |
|------|--------|-------------|
| `01-contacts.md` | CRM/Sales | Customers, suppliers, leads |
| `02-products.md` | Inventory/Sales | Products and services |
| `03-finance.md` | Finance | Chart of accounts, journal entries |
| `04-invoices.md` | Sales | Invoices and credit notes |
| `05-bills.md` | Purchases | Bills and supplier payments |
| `06-inventory.md` | Inventory | Warehouses, stock movements |
| `07-pos.md` | Point of Sale | Registers, shifts, transactions |
| `08-hr-payroll.md` | HR & Payroll | Employees, payroll runs |
| `09-crm.md` | CRM | Leads, opportunities, activities |
| `10-banking.md` | Finance | Bank accounts, transactions |
| `11-expenses.md` | Finance | Expense claims and categories |
| `12-studio.md` | Studio | Custom fields, automations |

## Testing Order

For best results, test in this order:
1. **Contacts** → Create customers and suppliers first
2. **Products** → Add products/services
3. **Finance** → Set up chart of accounts
4. **Inventory** → Configure warehouses
5. **Sales** → Create invoices
6. **Purchases** → Create bills
7. **Banking** → Record transactions
8. **HR** → Add employees
9. **Payroll** → Run payroll
10. **POS** → Open shifts and process sales
11. **CRM** → Manage leads and opportunities
12. **Reports** → Generate and verify reports

## Currency

All amounts are in **KES (Kenyan Shillings)** unless otherwise noted.
